# Data access and non-redistribution

This public repository contains **code only**. It intentionally contains no patient-level records, no derived datasets, no aggregate result tables exported from the credentialed databases, and no fitted MIMIC model artifacts.

## Source databases

- **MIMIC-IV v3.1** — https://doi.org/10.13026/kpb9-mt58
- **eICU Collaborative Research Database v2.0** — https://doi.org/10.13026/C2WM1R

Both source databases require the applicable PhysioNet credentialing/training/data-use agreement. Reproducers must obtain their own authorized access.

PhysioNet's current MIMIC guidance states that derived datasets or models should be treated as sensitive and, if shared, should be distributed through PhysioNet under the same agreement as the source data. Therefore this GitHub/Zenodo release distributes analysis code and documentation only. MIMIC-derived/eICU-derived datasets and fitted model artifacts are generated locally by authorized users and are excluded from this public release.
