# v1.0.0

Initial public code release for the manuscript:

**48-Hour Landmark Reassessment of MELD 3.0 in Critically Ill Patients With Cirrhosis: Incremental Prognostic Value and External Transportability**

The release contains complete analysis code and documentation but intentionally excludes source data, patient-level derivatives, aggregate result datasets, and fitted MIMIC model artifacts. The 72-hour fitted coefficient vectors are generated locally by `mimic/code/14b_export_h72_fixed_coefficients.py` under authorized MIMIC access.
