# GitHub and Zenodo publication

Recommended GitHub repository:

`pxiang977-hub/meld3-icu-landmark-reassessment`

Create it as a **Public** repository and do not initialize it with a README, license, or `.gitignore` because those are already supplied here.

Recommended description:

`Analysis code for 48-h MELD 3.0 landmark reassessment and fixed-coefficient external validation in critically ill patients with cirrhosis.`

After the repository content is on `main`, connect the repository in Zenodo's GitHub integration and create the GitHub release/tag `v1.0.0`. Zenodo should then archive that release. Verify title, creators/ORCIDs, license, version, description, and keywords before publishing the Zenodo record.

Do not add any MIMIC-IV/eICU-CRD data, derived datasets, aggregate export tables, patient-level predictions, or fitted MIMIC model artifacts to GitHub or Zenodo.
